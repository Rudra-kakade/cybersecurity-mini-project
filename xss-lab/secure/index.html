🔧 Why This Is Safe
❌ Vulnerable (innerHTML)
bodyDiv.innerHTML = comment.body;
// Parses HTML → <script> tags execute
// Event handlers (onerror, onload) fire
✅ Secure (textContent)
bodyDiv.textContent = comment.body;
// ALL input treated as plain text
// <script> renders as visible text, never runs
❌ Vulnerable PHP
echo "<div>" . $_POST['comment'] . "</div>";
// Raw output — XSS executes
✅ Secure PHP
echo "<div>" . htmlspecialchars($comment, ENT_QUOTES, 'UTF-8') . "</div>";
// HTML entities — safe text output
